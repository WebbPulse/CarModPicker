# CarModPicker Chrome Extension

A Chrome extension that allows you to quickly scrape part information from web pages and add them to your CarModPicker account with just a few clicks.

## Features

- **Quick Authentication**: Login with your CarModPicker credentials
- **Smart Scraping**: Automatically extracts product information from web pages:
  - Product name
  - Description
  - Price
  - Image URL
  - Brand
  - Part number/SKU
  - Product URL
- **Easy Part Creation**: Review and edit scraped data before creating parts
- **Category Selection**: Choose from available categories
- **Car Association**: Optionally associate parts with specific car models

## Installation

1. Build the extension first (see Development section below)
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer mode" (toggle in top right)
4. Click "Load unpacked"
5. Select the `chrome-extension/dist` directory (the built extension folder)
6. The extension icon should appear in your toolbar

## Usage

1. **Login**: Click the extension icon and login with your CarModPicker credentials
2. **Navigate to a product page**: Visit any website with product information
3. **Scrape**: Click the "Scrape Current Page" button in the extension popup
4. **Review**: Review the scraped data in the part creation dialog
5. **Edit**: Make any necessary edits (category, car association, etc.)
6. **Create**: Click "Create Part" to add it to your CarModPicker account

## Configuration

Click "Settings" in the login screen to configure:
- **API URL**: Set the base URL for the CarModPicker API (default: `https://carmodpicker.com/api`)

## Development

The extension is built with TypeScript for consistency with the main codebase.

### Setup

1. Install dependencies:
   ```bash
   cd chrome-extension
   npm install
   ```

2. Build the extension:
   ```bash
   npm run build
   ```

3. For development with watch mode (auto-compiles on file changes):
   ```bash
   npm run watch
   ```

### Development Workflow

**Important:** You don't need to delete and re-add the extension after changes!

1. **Run watch mode** in a terminal:
   ```bash
   npm run watch
   ```

2. **Make your changes** to TypeScript files in `src/`

3. **Reload the extension** in Chrome:
   - Go to `chrome://extensions/`
   - Find "CarModPicker Part Scraper"
   - Click the **reload button** (circular arrow icon) 🔄

4. **Test your changes**

**Note:** 
- Service worker (background.ts) changes require extension reload
- Content scripts update automatically on next page navigation
- Popup scripts update when you close/reopen the popup
- Manifest.json changes always require reload

See [DEVELOPMENT.md](./DEVELOPMENT.md) for detailed development workflow.

### Project Structure

- `src/`: TypeScript source files
  - `types.ts`: Type definitions for API responses
  - `background.ts`: Service worker for API communication
  - `content.ts`: Content script that scrapes product data from web pages
  - `popup.ts`: Popup UI logic
  - `options.ts`: Settings page logic
- `dist/`: Compiled JavaScript files (generated by TypeScript compiler)
- `manifest.json`: Extension configuration
- `popup.html/css`: Main UI for authentication and part creation
- `options.html`: Settings page

## Notes

- The extension requires authentication via your CarModPicker account
- 2FA-enabled accounts must login via the web app first
- Image uploads are handled automatically when creating parts
- The scraper works best on standard e-commerce product pages

## Permissions

The extension requires:
- `activeTab`: To access the current page content
- `storage`: To save authentication tokens and settings
- `scripting`: To inject content scripts
- `host_permissions`: To make API requests to CarModPicker
