# Site notes

Per-retailer notes on fetch blockers, DOM quirks, anti-bot measures, and anything else that surprised us while building or running an adapter. One file per site (e.g. `jegs.md`, `summit_racing.md`).

Write a note here when a retailer does something non-obvious that a future reader (or future-you) would need to rediscover: Cloudflare / Akamai challenges, JSON-LD quirks, sitemap oddities, rate-limit behavior, login walls, regional redirects, etc.

These notes are not the adapter's docstring — they are the *why* and the *history*. Short is fine.
