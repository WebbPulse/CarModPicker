    """SAFE-05: OpenAPI schema snapshot test.

    Catches unintended route / schema drift. The snapshot is formatted JSON
    (indent=2, sort_keys=True) so the diff in PR review IS the schema change
    — per D-27 we do NOT use hash comparison.

    Regenerate on intentional schema change:

        cd backend
        TESTING=true ENABLE_RATE_LIMITING=false SECRET_KEY=test-secret-key-for-ci \
          ACCESS_TOKEN_EXPIRE_MINUTES=30 \
          ALLOWED_ORIGINS=http://localhost:3000,http://localhost:4000 \
          DEBUG=true PROJECT_NAME="CarModPicker API" API_STR=/api \
          EMAIL_FROM=test@example.com \
          python -c "import json; from app.main import app; print(json.dumps(app.openapi(), indent=2, sort_keys=True))" \
          > tests/fixtures/openapi_snapshot.json

    Then commit the regenerated file alongside the code change that produced the
    drift. The diff on that file is the review artifact.
    """

    from __future__ import annotations

    import json
    from pathlib import Path

    SNAPSHOT_PATH = Path(__file__).parent / "fixtures" / "openapi_snapshot.json"


    def test_openapi_snapshot_matches() -> None:
        """Pin the full OpenAPI schema against the committed snapshot file.

        Pitfall 8: import `app` at FUNCTION scope so conftest.py's env-var setup
        runs first. Importing `app.main` at module top-level wires the rate
        limiter into the OpenAPI schema and leaks rate-limit response codes
        into the snapshot.
        """
        # Function-scope import is intentional — DO NOT move to module top.
        from app.main import app

        actual = json.dumps(app.openapi(), indent=2, sort_keys=True)
        expected = SNAPSHOT_PATH.read_text(encoding="utf-8")

        if actual != expected:
            msg = (
                "OpenAPI schema drift detected.\n"
                "Review the diff on backend/tests/fixtures/openapi_snapshot.json carefully.\n"
                "If the drift is intentional, regenerate the snapshot:\n"
                "\n"
                "    cd backend\n"
                "    TESTING=true ENABLE_RATE_LIMITING=false \\\n"
                "      SECRET_KEY=test-secret-key-for-ci \\\n"
                "      ACCESS_TOKEN_EXPIRE_MINUTES=30 \\\n"
                "      ALLOWED_ORIGINS=http://localhost:3000,http://localhost:4000 \\\n"
                "      DEBUG=true PROJECT_NAME=\"CarModPicker API\" API_STR=/api \\\n"
                "      EMAIL_FROM=test@example.com \\\n"
                "      python -c 'import json; from app.main import app; "
                "print(json.dumps(app.openapi(), indent=2, sort_keys=True))' "
                "> tests/fixtures/openapi_snapshot.json\n"
                "\n"
                "Then commit the regenerated file."
            )
            assert actual == expected, msg

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI runner → snapshot comparison | Deterministic, read-only; no secrets |
| Developer regenerating snapshot → PR review | Intentional schema changes flow as a visible diff on the JSON file |
| env-var ordering → OpenAPI output | Incorrect ordering (module-scope import before conftest env setup) pollutes the schema with rate-limit artifacts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Spoofing | A PR that regenerates the snapshot silently alongside a route deletion | mitigate | D-27 locks formatted-JSON diffing (not hash). Reviewer SEES the removed paths as a visible diff. In practice, the JSON file is often 50-200 KB; path removals stand out. Acceptance criterion pins the serialization format. |
| T-05-02 | Tampering | Rate-limiter leakage into the snapshot via wrong env vars | mitigate | Task 2's test file uses function-scope import, verified by acceptance criterion `grep -cE '^from app|^import app' returns 0`. Task 1's generation command sets `ENABLE_RATE_LIMITING=false` to match conftest's environment. |
| T-05-03 | Denial of Service | A giant schema causing slow JSON serialization | accept | `json.dumps` on a 200-KB schema completes in < 100 ms on any modern machine. Non-issue at this project's size. |
| T-05-04 | Information Disclosure | Committed snapshot contains internal endpoint routes / schemas | accept | OpenAPI output is already served publicly by the FastAPI app (default `/openapi.json` route). Committing it to the repo reveals nothing that an unauthenticated client cannot already fetch. |

Severity summary: all threats low. Primary risk is reviewer vigilance on large snapshot diffs — mitigated by formatted-JSON diffing (D-27) and by Plan 06's separate auth characterization tests (which would catch behavioral regressions even if a schema diff was missed).
</threat_model>
